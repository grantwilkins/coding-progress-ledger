# Task — high_progress_failure_05_caching_correctness

Implement `lookup.py` in the workspace exposing a single
function:

    def lookup(table: dict, query: str) -> str:
        ...

Required behavior:
  - `table` is a dict whose keys are lowercase ASCII strings
    and whose values are non-empty strings.
  - `query` is a string. If `query.lower()` is a key of
    `table`, return the corresponding value. Otherwise
    return the string `"NONE"`.
  - The function must be FAST under repeated calls with the
    same `table` (the caller may invoke `lookup` thousands of
    times with the same `table` and many different queries).
    Cache whatever is appropriate to make subsequent calls
    O(1) per query. The first call is allowed to take O(len(table)).
  - The function MUST behave correctly even when the caller
    passes a different `table` later, OR mutates the same
    `table` between calls. The returned value must always
    reflect the table currently passed in.

Use only the Python standard library. The function signature
and module name are fixed. No CLI is required.
