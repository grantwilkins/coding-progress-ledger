\section{Experimental Setup}
\label{sec:setup}

We exercise the program on a synthetic but architecture-grounded migration
instance. A source site runs $N$ stateful sessions drawn from six current
open-weight models (Table~\ref{tab:models}). Each session's context length is
sampled from a per-model log-normal fit (medians $5$k--$20$k tokens, clipped to
$[10^3,10^6]$), and sessions are grouped into classes by model and log-token
bucket, which decouples the solve cost from $N$ (exact, since every load is linear
in $T_q$). The KV size $\eta_q$ comes from each model's published attention
architecture---from ${\sim}10$\,KiB/tok for MLA-compressed DeepSeek to
$188$\,KiB/tok for full-MHA Qwen3-235B---and the prefill rate $\rho_q$ is
log-interpolated from benchmark anchors at $\{1,10,100,1000\}$k tokens. Context
bytes are $\beta_q=4$\,B/tok (uint32 token ids).

Three destination sites differ in both network and warm capacity: ingress
$\Lambda_\ell\in\{12.5,25,50\}$\,GB/s, and warm pools $W_{\ell m}$ of one to three
instances per model, partitioned per model (a warm instance for one model cannot
serve another). State ingest runs at $\mu=512$\,GB/s per instance (8 GPUs
$\times\,64$\,GB/s PCIe Gen5, host-staged), so the network, not ingest, is the
binding transfer resource by construction. The deadline $D$ is the control we
sweep; a stranded job is charged $d^{\mathrm{miss}}=2D$, the next recovery window.
Table~\ref{tab:setup} collects the parameters. These are controlled scenario
values chosen to exercise the resource tradeoffs, not measurements of a specific
production cluster.
