## Measurement

Power is sampled with `nvidia-smi` at the configured 0.1 s interval in the
handoff result (the joint node default is 0.25 s unless overridden). Each row
contains monotonic/wall time, GPU index, watts, utilization, memory, and
validity. Windowed power is summarized as mean and median over phase rows in
`power_summary.csv`; the exact inclusion boundary is `UNKNOWN` (searched
`migration_profiler.py`, `network_campaign.py`).

For the standard migration profiler, timestamps mean: initial start/end are
the initial request boundaries; `pause_start` is quiesce; `idle` is catch-up
eligibility; `catch_up_start/end` bound catch-up; `switch_start/end` bound route
switch/commit; and `first_byte_ns` is the first streamed response byte. The
network handoff result instead records `handoff_start/end`, `sleep_start`, and
`sleep_ready`; exact mapping to migration-start/transfer-complete/quiesce/
catch-up/switch is `UNKNOWN`. TTFT is request start to first byte. Shed
credited per session is `UNKNOWN` for this network experiment; no checked-in
network result defines a per-session shed formula.

Chrony is used and checked against a 2 ms limit; recorded uncertainty is
0.009919 ms (source), 0.015834 ms (East), and 0.010530 ms (West) in one host
report. PTP is `/dev/ptp0`. Cross-region timestamp reconciliation uses each
event’s monotonic and wall nanoseconds; a formal offset/reconciliation formula
is `UNKNOWN`.

## Discrepancies from the two-A100 experiment

Confirmed differences:

- Cross-region experiment: three Azure `Standard_NC24ads_A100_v4` Spot VMs,
  one A100 each, one source plus two destinations. The two-A100 mechanism
  campaign requests one node with two `GPU_SKU:A100_SXM4` 80-GB GPUs under
  Slurm (`mechanism_validation_campaign.py`).
- Cross-region experiment has Sweden→East/West WAN paths, measured RTT,
  iperf bandwidth shaping, a source-side Redis/RESP L2, and remote TCP proxy
  routes. The two-A100 campaign is a single-node local run; its physical
  network path and L2 placement are `UNKNOWN` in checked-in artifacts.
- Cross-region scenarios use 8 sessions, 7 conditions, 6 policies, and 3
  repeats, including destination sets of two nodes. The mechanism campaign
  uses one session, one 28,000-token context, 2,048 activity tokens, two
  methods (`kv_transfer`, `replay`), and 5 repeats.
- Cross-region source launch explicitly enables sleep mode and uses the
  observed MP startup with 1,180,672 KV tokens. The two-A100 artifact’s
  observed startup capacity and source sleep flag are `UNKNOWN` (searched
  `outputs/mechanism-validation*` and its run root).

0.5.1, TP=1 per serving process, MP `engine_driven` connector, BF16 compute
