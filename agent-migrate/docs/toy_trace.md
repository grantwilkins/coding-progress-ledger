# Canonical toy trace — `examples/traces/toy_subagent_trace.jsonl`

Generated by `agent_migrate_agent.adapters.synthetic.SyntheticConfig()` with default values. The committed JSONL is regeneratable byte-for-byte from the default config; do not edit it by hand.

## Adversarial by design

This trace is constructed so a no-reuse baseline must duplicate shared state. Showing a duplication-factor gap on this trace proves the framework can express the phenomenon; it does **not** prove the phenomenon exists in real workloads. See `TASKS.md` § 0 for framing rules.

## `tau` sensitivity

`shared_state_aware` (Workstream D2) groups nodes whose pairwise shared-state edge weight exceeds `tau` tokens.

- **`tau = 1`** — any sharing groups. The 200-token `system_prefix` glues all four nodes into a single component, so the policy collapses to "place everything at one site." This is *exactly* why `tau` exists.
- **`tau = 1000`** — the `system_prefix` edge (weight 200) drops out. Components become: `{S1, S2, S3, S4}` (still glued by `repo_context`'s 8000 tokens) and the workspace edge between S2/S4 (workspace token weight is 0, so this edge is also pruned at any positive `tau`). Effectively the same component as `tau=1` for this trace, dominated by `repo_context`.
- **`tau = 10000`** — every edge drops; the policy degenerates to per-node placement.

The toy trace's small `system_prefix` is included specifically to motivate `tau` — without it, every shared-state edge has the same scale and the knob looks decorative.
