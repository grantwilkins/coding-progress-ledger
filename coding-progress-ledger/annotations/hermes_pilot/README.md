# annotations/hermes_pilot

Hermes pilot retrospective annotations.

## Contents

- `hermes_pilot_*.json`: per-run annotation specs.
- `hermes_pilot_*.notes.md`: evidence notes and interpretation rationale.

## Usage

Run `scripts/annotate_pilots_from_spec.py` against these specs to regenerate pilot ledgers and derived progress artifacts.

## Notes

This folder is the baseline Hermes annotation pass. Protocol revisions should be recorded in new versioned folders, not by rewriting these files.
